Skill Verify

A deterministic gate for SKILL.md files: verify the files a skill claims to ship, reject path escapes, and flag high-signal unsafe instruction text.

GitHub repository GitHub Marketplace Detailed guide

30-second check

git clone https://github.com/wu350891451-jpg/skill-verify.git
cd skill-verify
python3 scripts/skill_verify.py demo/good-skill
python3 scripts/skill_verify.py demo/broken-skill

The first command exits 0. The second exits 1 and names the missing local path.

What it checks

AreaMechanical check
StructureFrontmatter, kebab-case name, directory match, description
ReferencesMarkdown links, HTML attributes, scripts, assets, and known local files
ContainmentPaths may not escape the skill directory
Instruction riskOverride, disclosure, exfiltration, remote shell, destructive deletion, hidden comments
OutputText, JSON, and SARIF with stable rule ids

GitHub Action

- uses: wu350891451-jpg/skill-verify@v0.1.0

Boundary

A pass means the checked files satisfy the current rules. It is not a sandbox, a signature, or a proof that a skill is harmless.

MIT licensed. Python 3.8+. No runtime dependencies.
